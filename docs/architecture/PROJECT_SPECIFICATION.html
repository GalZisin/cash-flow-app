📋 סקירה כללית - Overview

🎯 מטרת המערכת

מערכת לניהול תזרים מזומנים אישי/משפחתי בעברית, המאפשרת מעקב אחר הכנסות, הוצאות, השקעות, פריסות תשלומים ויעדים פיננסיים. המערכת כוללת סימולציה מתקדמת לבדיקת השפעת יעדים על תזרים המזומנים לפני יישומם.

👥 משתמשי קצה
  • משתמשים פרטיים המנהלים תקציב אישי
  • משפחות המתכננות רכישות גדולות
  • אנשים המעוניינים בתכנון פיננסי מתקדם
  • משתמשים דוברי עברית (ממשק RTL מלא)
✨ יכולות מרכזיות
  • ניהול תזרים מזומנים חודשי עם תצוגה טבלאית
  • מעקב אחר פריסות תשלומים והשקעות
  • ניהול יעדים פיננסיים עם ניתוח היתכנות
  • סימולציה של תזרים מזומנים לבדיקת יעדים
  • ויזואליזציות גרפיות (D3, Charts)
  • אנימציות חכמות (GSAP)
  • דוחות AI וצ'אט עם בינה מלאכותית
  • ממשק רספונסיבי בעברית

🏗️ ארכיטקטורה - Architecture

📐 מבנה האפליקציה

Client-Server Architecture עם הפרדה מלאה בין Frontend ו-Backend:

🎨 Frontend (Angular)
  • Angular 21 Standalone Components
  • Lazy Loading לכל המודולים
  • Signal-based State Management
  • RxJS לניהול אסינכרוני
  • Angular Material UI Components
  • Bootstrap 5 לסטיילינג
⚙️ Backend (Node.js)
  • Express.js REST API
  • File-based Data Storage (JSON)
  • Repository Pattern
  • Centralized Error Handling
  • Logging System (Winston)
  • CORS Support

💰 MonthData - נתוני חודש בתזרים
interface MonthData {
  month: string;                 // תאריך החודש (ISO)
  startingBalance: number;       // יתרת פתיחה
  income: number;                // הכנסות
  mortgagePayment?: number;      // תשלום משכנתא
  loanPayment?: number;          // תשלום הלוואה
  installmentsPayment?: number;  // סך פריסות
  additionalIncomes?: {          // הכנסות נוספות
    description: string;
    amount: number;
  }[];
  regularExpenses?: ExpenseItem[]; // הוצאות קבועות
  specialExpenses?: ExpenseItem[]; // הוצאות חד-פעמיות
  endingBalance: number;         // יתרת סגירה
  savings?: number;              // חיסכון מצטבר
  rowColor?: string;             // צבע שורה (UI)
}
🎯 FinancialGoal - יעד פיננסי
interface FinancialGoal {
  id: string;
  name: string;
  description?: string;
  type: GoalType;               // PURCHASE | LOAN_PAYOFF | SAVINGS | PROJECT
  targetAmount: number;         // סכום יעד
  targetDate: string;           // תאריך יעד (YYYY-MM)
  loanDetails?: LoanDetails;    // פרטי הלוואה (אם רלוונטי)
  schedule?: GoalSchedule;      // סוג לוח תשלומים
  priority: number;             // עדיפות (1 = הכי חשוב)
  analysis?: GoalAnalysis;      // ניתוח היתכנות
  completed: boolean;
  createdDate: string;
  updatedDate: string;
}

🎯 פיצ'רים - Features

💰 תזרים מזומנים (Cash Flow)
  • טבלה חודשית עם חישובים אוטומטיים
  • הוספה/עריכה/מחיקה של הוצאות והכנסות
  • ברירות מחדל להעתקה לחודשים חדשים
  • צביעת שורות לפי מצב היתרה
  • ייצוא לקובץ PDF
  • עריכה inline בטבלה
🎯 יעדים פיננסיים (Goals)
  • יצירת יעדים עם סוגי תשלום שונים
  • תשלום חד-פעמי / הלוואה / אבני דרך
  • ניתוח אוטומטי של היתכנות
  • תצוגת סטטוס (ירוק/כתום/אדום)
  • עדיפויות ליעדים
  • המלצות לשיפור
🔄 סימולציה (Simulation)
  • טבלת תזרים מזומנים נפרדת לסימולציה
  • יעדים משפיעים **רק** על הסימולציה, לא על התזרים המקורי
  • עריכה חופשית של נתוני הסימולציה
  • כפתור רענון - מעדכן את הסימולציה מהתזרים המקורי
  • רענון מאפס את כל היעדים (דורש אישור)
  • הסימולציה לעולם לא משנה את התזרים המקורי
💳 פריסות תשלומים (Installments)
  • ניהול פריסות עם תשלומים חודשיים
  • מעקב אחר תשלומים שבוצעו
  • שלושה סוגי פריסות: ידני/הלוואה/אבני דרך
  • אינטגרציה אוטומטית לתזרים המזומנים
  • גרפים ותצוגות חזותיות
📈 השקעות (Investments)
  • מעקב אחר השקעות מרובות
  • תמיכה במטבעות שונים
  • גרף Sankey של זרימת כספים
  • חישוב תשואות
  • סוגי השקעות שונים
🤖 עוזר AI
  • צ'אט עם בינה מלאכותית (Ollama)
  • ניתוח נתונים פיננסיים
  • המלצות והצעות
  • יצירת דוחות אוטומטית
  • שמירת שיחות
🆕 פיצ'ר מיוחד: מערכת סימולציה

המערכת כוללת מנגנון ייחודי של סימולציה המאפשר למשתמשים לבדוק את ההשפעה של יעדים פיננסיים על תזרים המזומנים בטבלה נפרדת. חשוב: היעדים משפיעים רק על טבלת הסימולציה, ולא על התזרים המקורי. כפתור "רענן מהתזרים המקורי" מאפס את כל הסימולציה והיעדים, ומעתיק מחדש את הנתונים מהטבלה המקורית.

🔄 תקשורת בין קומפוננטות

GoalsComponent ↔ CashFlowTableComponent

  • GoalsComponent שולח נתונים דרך @Input isSimulation
  • GoalsComponent מעביר נתוני סימולציה דרך @Input simulationData
  • CashFlowTableComponent מציג את הנתונים בהתאם למצב

Services ← Components

  • כל קומפוננטה עובדת עם שירות ייעודי (Dependency Injection)
  • השירותים מחזירים RxJS Observables
  • הקומפוננטות מאזינות לשינויים דרך async pipe או subscribe

🔄 תהליך עבודה טיפוסי של שירות

דוגמה: CashFlowService.getCashFlow()
// 1. קומפוננטה מבקשת נתונים
this.cashFlowService.getCashFlow()
  .subscribe(data => this.months = data.months);

// 2. השירות שולח HTTP Request
this.http.get<{months: MonthData[]}>('http://localhost:3000/api/cash-flow')

// 3. השרת מעבד את הבקשה
app.get('/api/cash-flow', cashFlowRoutes);

// 4. Repository קורא את הקובץ
const data = await fs.readFile('data/cash-flow.json');

// 5. Response חוזר דרך כל השכבות
return { months: JSON.parse(data) };

🔄 תהליכים - Process Flows

📝 תהליך יצירת יעד חדש

1. משתמש מלא טופס יעד חדש
GoalsComponent - Form Validation
⬇️
2. שליחת יעד חדש לשירות
GoalsService.createGoal(newGoal)
⬇️
3. HTTP POST Request
POST /api/goals + Body: FinancialGoal
⬇️
4. שרת מאמת ושומר
goals.routes.js → GoalService → Repository
⬇️
5. Response עם היעד החדש
Status 201 + Created Goal Object
⬇️
6. עדכון UI
GoalsComponent מציג את היעד החדש + Toast הצלחה

🎯 תהליך עבודה עם סימולציה ויעדים

1. משתמש יוצר יעדים חדשים
GoalsComponent - טופס יעדים
⬇️
2. יעדים נשמרים ב-GoalsService
POST /api/goals
⬇️
3. CashFlowSimulationService מעדכן אוטומטית
combineLatest מאזין לשינויים ביעדים
⬇️
4. הסימולציה מתעדכנת
updateSimulation() - שכפול תזרים + הוספת יעדים
⬇️
5. טבלת הסימולציה מציגה את התוצאה
CashFlowTableComponent (isSimulation=true)
⬇️
6. "רענן מתזרים מקורי" - איפוס הכל
מחיקת יעדים + טעינה מחדש מהמקור
⚠️ הערה חשובה:

התזרים המקורי אף פעם לא משתנה מהיעדים. רק הסימולציה מושפעת. כדי לעדכן את התזרים המקורי, משתמשים צריכים לערוך אותו ידנית בטאב "תזרים מזומנים".
