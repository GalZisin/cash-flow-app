# גרפי מגמות התזרים (יועץ AI → דאשבורד)

אזור "מגמות התזרים" בטאב הדאשבורד של יועץ ה-AI מציג את התזרים לאורך זמן: יתרה, הכנסות מול הוצאות וחיסכון נטו, עם תחזית של כמה שנים קדימה. הכל מחושב בצד הלקוח מחודשי טבלת התזרים, בלי קריאות שרת ובלי AI.

## מה רואים

| חלק | תוכן |
| --- | --- |
| שורת סינון | תקופה (חודשי / רבעוני / שנתי), טווח (שנה / 3 / 5 / הכל), הצגת ממוצעים, מעבר גרפים / טבלה |
| תחזית | שנות תחזית (0-30, מחוון וכפתורים מהירים), צמיחת הכנסות ועליית הוצאות בשנה (%), בסיס התחזית (ממוצע 3 / 6 / 12 / 24 חודשים אחרונים), איפוס |
| KPI | יתרה היום, הכנסה / הוצאה / חיסכון חודשי ממוצע ושיעור חיסכון, יתרה צפויה בסוף הטווח ושינוי מהיום |
| מסלול היתרה | שטח וקו של יתרת סוף תקופה. נתונים בקו מלא, תחזית בקו מקווקו על רקע "תחזית", קו "היום" |
| הכנסות מול הוצאות | עמודות לכל תקופה, קווי ממוצע מקווקווים (תקופות שאינן תחזית) |
| חיסכון נטו | עמודות עודף (ירוק) / גירעון (אדום) וממוצע נע של 3 תקופות |
| טבלה | אותן תקופות בטבלה: הכנסות, הוצאות, נטו, שיעור חיסכון, יתרה וסימון "מתוכנן" / "תחזית" |

ריחוף (או חיצים במקלדת כשהגרף בפוקוס) מציג tooltip עם כל הערכים של התקופה. הבחירות נשמרות ב-localStorage (`cf-charts-settings`).

## איך מחושב

- **טווח**: חלון סביב החודש הנוכחי, X שנים אחורה ו-X שנים קדימה (כולל תחזית). כך הוא משנה את התצוגה גם כשרוב הטבלה עתידית. "הכל" לא מסנן. תחזית ארוכה מהטווח נחתכת בגרף, אז לתחזית של 10 שנים צריך לבחור "הכל".
- **חודש בפועל / מתוכנן**: חודש עד החודש הנוכחי הוא "בפועל", חודש עתידי שקיים בטבלת התזרים הוא "מתוכנן".
- **הכנסות / הוצאות לחודש**: `CashFlowCalculationService.totalIncome` / `totalExpenses` (אותו חישוב כמו בטבלה).
- **תחזית**: אחרי החודש האחרון בטבלה. בסיס = ממוצע ההכנסות וההוצאות ב-N החודשים האחרונים, עם צמיחה שנתית מצטברת (מחולקת לחודשים). היתרה ממשיכה מהיתרה האחרונה בטבלה.
- **צבירה לרבעון / שנה**: סכום ההכנסות, ההוצאות והנטו, יתרת סוף התקופה, והסוג של החודש האחרון בתקופה.
- **ממוצעים ב-KPI**: ממוצע חודשי על החודשים שבטווח ואינם תחזית.

הגרף מצויר ב-SVG מתבנית Angular (d3-shape רק לנתיבי הקו והשטח), כל הצבעים מ-tokens של ערכת הנושא (`--cf-primary`, `--cf-success-solid`, `--cf-danger-solid` ...), כך שהוא מתחלף עם הערכה ועם מצב כהה. ציר הזמן תמיד משמאל לימין, גם בעברית.
