# ייצוא התזרים: Excel ודוח PDF

בכותרת טבלת התזרים יש שני כפתורים: **ייצא Excel** ו-**ייצא PDF**. שניהם רצים בצד הלקוח בלבד, בלי נתיב שרת ייעודי.

## Excel

- **מקור הנתונים**: קריאה טרייה מהשרת (`CashFlowService.fetchSaved()` -> `GET /api/cash-flow`), כלומר מה ששמור ב-SQL Server, בלי שינויים שעוד לא נשמרו. במצב סימולציה (יעדים) הנתונים לא קיימים בשרת, ולכן מייצאים את מה שמוצג בטבלה.
- **שם הקובץ**: `cash-flow-YYYY-MM-DD.xlsx` לפי תאריך הייצוא.
- **גיליון "תזרים"**: אותן עמודות ובאותו סדר כמו בטבלה (בלי עמודת הפעולות, עם עמודת חיסכון). RTL, שורת כותרת ועמודת החודש קפואות, סינון אוטומטי, צבע השורה כמו בטבלה (ירוק / צהוב / אדום), פירוט הפריטים של הכנסות נוספות / הוצאות שוטפות / מיוחדות בהערה על התא, ושורת סה"כ בסוף. סכומים שלמים עם ₪, שלילי באדום.
- **גיליון "פירוט"**: שורה לכל פריט (חודש, סוג, תיאור, קטגוריה, סכום), עם סינון אוטומטי.
- **ExcelJS** נטען רק בלחיצה על הכפתור (dynamic import), כדי לא להגדיל את ה-bundle הראשי. צבעי הקובץ קבועים בקוד (ARGB) כי זה קובץ אקסל ולא SCSS.
- כשל בייצוא מציג snackbar (`CASH_FLOW.EXPORT_EXCEL_FAILED`).

## דוח PDF

"ייצא PDF" פותח דיאלוג לבחירת התוכן, ואחרי "הפק PDF" נפתח חלון ההדפסה של הדפדפן (שם בוחרים "שמור כ-PDF").

| בדיאלוג | מה |
| --- | --- |
| טווח מהיר | כל התקופה, השנה הנוכחית, 12 החודשים האחרונים, 12 החודשים הבאים. הטווח נחתך לחודשים שקיימים בטבלה |
| מחודש / עד חודש | טווח ידני (כולל שני הקצוות). התחלה אחרי סיום = שגיאה |
| עמוד סיכום עם גרפים | ארבעה גרפים: הכנסות מול הוצאות, יתרה בסוף החודש, חיסכון חודשי (עודף / גירעון), לאן הלך הכסף |
| פירוט לפי חודש | כל פריטי ההכנסות וההוצאות של כל חודש |

הבחירה האחרונה נשמרת לפתיחה הבאה של הדיאלוג (כל עוד היא תקפה).

**חישובים**: כל מספר בדוח מחושב על הטווח שנבחר בלבד (`summarizeRange`): יתרת פתיחה = תחילת החודש הראשון, יתרת סגירה = סוף החודש האחרון, סה"כ הכנסות (כולל נוספות), סה"כ הוצאות (משכנתא, הלוואות, פריסות, שוטפות, מיוחדות), נטו, ממוצעים לחודש ושיעור חיסכון. "לאן הלך הכסף" מקבץ משכנתא, הלוואות, פריסות וכל קטגוריית הוצאה; מעבר ל-8 פריטים הקטנים מתקפלים ל"שאר ההוצאות".

**הדפסה**:

- `CashFlowPrintReportComponent` מחליף את הטבלה בזמן הדפסה (`window:beforeprint` / `afterprint`). טבלת החודשים מתחילה בעמוד משלה.
- הגרפים הם SVG סטטי (`CashFlowReportChartsComponent`), בצבעי tokens של ערכת הנושא.
- הדוח תמיד מודפס בצבעי מצב בהיר, גם כשהאפליקציה במצב כהה, ומצב כהה חוזר אחרי ההדפסה.
- **שם הקובץ**: "שמור כ-PDF" לוקח את השם מ-`document.title`, ולכן לפני ההדפסה הכותרת מוחלפת ל-`cash-flow-report-YYYY-MM_YYYY-MM` (חודש אחד: `cash-flow-report-YYYY-MM`) ומשוחזרת אחריה.
- Ctrl+P בלי הדיאלוג מדפיס את כל התקופה עם גרפים ופירוט, ובאותו כלל שם קובץ.
