חלופות ל-Ollama מקומי איך לחבר את עוזר ה-AI של Cash Flow App למודל שלא תופס את ה-CPU של המחשב: Ollama על מחשב אחר, או ספק API חינמי. נכון ל-2026-10-09.

איך האפליקציה מתחברת למודל

השרת בונה סיכום פיננסי קומפקטי (יתרות, ממוצעים, הלוואות, תחזית) ושולח רק אותו למודל, לעולם לא את הנתונים הגולמיים. הספק נבחר בקובץ server/.env בלי שינוי קוד: AI_PROVIDER=ollama מדבר בפרוטוקול של Ollama, AI_PROVIDER=openai מדבר עם כל API תואם OpenAI. הדפדפן לא מכיר את הספק ולא רואה את מפתח ה-API.

הקוד: server/services/ai.service.js. בדיקות מול ספק מדומה: server/test/ai-providers.test.js. תיעוד: docs/ai/AI_PROVIDERS.md.
